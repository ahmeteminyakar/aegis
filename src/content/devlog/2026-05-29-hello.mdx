This is the first entry. There is no hardware yet. There is no PCB,
no firmware, no bench data. There is a thermal budget on a napkin and
a control-loop sketch that has not been simulated.

The devlog will document the build between that state and a working
Aegis wristband. What I expect to write about: TEC sizing math, PWM
duty-cycle tradeoffs, sensor-fusion for the adaptive mode, enclosure
prints that did not fit, firmware that misbehaved.

What I will not write: marketing posts, roadmap updates dressed as
content, or anything that claims a result before the bench shows it.

If you want context on the device itself, the [Aegis page](/) has
the mechanism and the constraints. The honest ones.
